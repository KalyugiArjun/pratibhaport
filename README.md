## 🚀 Running Locally

### Option 1: Direct Double Click
Simply double-click `index.html` in your file explorer to open it immediately in any web browser.

### Option 2: Live Node Server
```bash
# Start local server on port 3000
npm start
# or: node server.js
```
Then visit [http://localhost:3000](http://localhost:3000).
